# NEXA AI Agent

## Overview
NEXA is an AI-powered agentic commerce solution designed to help customers discover suitable products through a conversational experience while helping merchants understand customer intent and identify revenue opportunities.

## Problem
Customers often struggle to find the right product among numerous options, while merchants may lose potential sales without understanding why customers leave.

## Solution
NEXA uses AI-driven conversations to understand customer requirements and provide relevant, explainable product recommendations. It also provides merchant-focused insights to identify lost intent and potential growth opportunities.

## Key Features

- 🤖 Conversational AI Shopping
- 🧠 Customer Intent Understanding
- ⭐ Personalized Product Recommendations
- 🔍 Explainable Recommendations
- 📊 Merchant Analytics
- 🚨 Lost Intent Detection
- 📈 AI Growth Actions
- 🤝 Connected Merchant Network
- 🧾 Transparent Audit Trail

## How It Works

Customer Query
→ AI Q&A
→ Intent Understanding
→ Product Recommendations
→ Product Selection

If a purchase is not completed:
→ Lost Intent Detection
→ Merchant Analytics
→ AI Growth Opportunity

## Tech Stack

- Frontend: React
- Backend: Node.js
- AI-powered conversational interface
- Razorpay Test Mode APIs
